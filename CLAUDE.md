# UnoSite – regler

**ABSOLUT REGEL: Ingen personfølsomme oplysninger må nogensinde komme i dette repo.**
Repoet er offentligt. Det gælder filer, commit-beskeder, PR-tekster, kommentarer og branch-navne.

Må aldrig skrives:
- E-mailadresser (undtagen GitHubs `noreply`-adresser), telefonnumre, adresser
- Fulde navne, fødselsdatoer, CPR-numre
- Tokens, nøgler, adgangskoder eller andre hemmeligheder
- Oplysninger fra brugerens konto, andre sessioner eller private repos

Tjek før hver commit: `git diff --cached` må ikke indeholde noget af ovenstående.
Er du i tvivl, så lad være og spørg brugeren.

Tilladt: forfatternavnet "Dennis M" i git-historikken og GitHub-brugernavnet "UnoSite".

Chat altid på dansk. Se skillen `unosite-profil` for viden om opbygningen.
